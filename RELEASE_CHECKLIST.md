# Release Checklist

Before publishing publicly:

- [ ] Confirm the release ZIP contains no game files.
- [ ] Confirm `LICENSE` is included.
- [ ] Confirm credits mention Joao Lucas / Megadroidgames and JuniorD-Isael.
- [ ] Confirm release DLL hashes are listed in the release notes.
- [ ] Confirm installer creates a backup before replacing files.
- [ ] Confirm the package installs on a clean folder copy.
- [ ] Add screenshots only if they do not expose private account data.
- [ ] Mark the release as experimental.
- [ ] Ask users to attach `ForzaFix_iGPU_.log` for bug reports.
- [ ] Avoid promising online compatibility or anti-cheat safety.
