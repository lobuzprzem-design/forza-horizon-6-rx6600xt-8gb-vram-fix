Uninstall / rollback
====================

1. Close Forza Horizon 6.
2. Open the folder that contains forzahorizon6.exe.
3. Delete:
   - d3d12.dll
   - dxgi.dll
4. Restore the original amd_ags_x64.dll from the backup folder created by the
   installer.
5. If you installed manually and amd_ags_x64_real.dll is the original game
   file, copy amd_ags_x64_real.dll back to amd_ags_x64.dll.

If the game does not start after uninstalling, verify that the original
amd_ags_x64.dll is present next to forzahorizon6.exe.
